# 脈衝 PULSE — 益智問答遊戲

地理・歷史・人文・科技・Python・娛樂・趣聞・即時新聞，八大主題 + 綜合挑戰，題庫 873 題（不含即時新聞）。地理、歷史、人文還可以再篩選台灣／中國／世界。Python(Flask)後端 + 手機友善的 HTML/JS 前端。

## 快速開始（桌面一鍵啟動）

- **Windows**：連點兩下 `啟動-Windows.bat`，會自動開啟主持台。
  要放到桌面：在這個檔案按右鍵 →「傳送到」→「桌面（建立捷徑）」。
- **macOS**：連點兩下 `啟動-Mac.command`（第一次若被擋，按右鍵 →「打開」）。
  要放到桌面：按住 <kbd>⌘</kbd>+<kbd>⌥</kbd> 把檔案拖到桌面，就會建立替身。
- **Linux**：執行 `./啟動-Linux.sh`。

## 手機加到主畫面（像 App 一樣用）

本站是 PWA，可以加到手機主畫面，開啟後沒有網址列，和 App 一樣：

- **Android／Chrome**：首頁會出現「加到手機主畫面」按鈕，或用瀏覽器選單的「安裝應用程式」。
- **iPhone／Safari**：按下方的「分享」→「加入主畫面」。
- 主畫面圖示長按還有捷徑：加入考場、主持台、班級積分。

> 加到主畫面只是把網頁包成 App 外觀，**遊戲仍需要老師的電腦在同一個 Wi-Fi 下執行 `app.py`**。

## 手動啟動

```bash
pip install -r requirements.txt
python app.py
```

- 電腦瀏覽器開 http://127.0.0.1:5000
- 手機（和電腦同一個 Wi-Fi)開 `http://<電腦的IP>:5000`

## 兩種模式

首頁可以切換「單人闖關」和「多人對戰」。

### 課堂當天這樣操作（個人賽・老師控題）

1. **上課前**（在自己的電腦）
   ```bash
   pip install -r requirements.txt
   python app.py
   ```
   記下電腦的區網 IP（開考場後畫面上的加入網址就會顯示）。確認手機和電腦連同一個 Wi-Fi。
2. **開考場**：瀏覽器開 `http://127.0.0.1:5000/host`
   - 主題選 **Python**，題數選 5／10／15／20
   - 每題秒數選 **手動**（由你按鈕控制每題的開始與結束）
   - 賽制留 **個人賽**
   - 填**班級代碼**（例如 `Python-115-1`）→ 第一次會顯示**六碼管理碼，請記下來**
   - 要對學號的話可以順便上傳分組名單 CSV（沒有也行，學生自己填學號姓名）
3. **學生登錄**：手機掃 QR code 或開首頁輸入四位數房號，填學號與姓名後進入等待畫面。主持台會顯示報到名單。
4. **每一題**
   - 你按「**開始考試**」或「**下一題**」→ 題目同時出現在大螢幕和所有人手機上，開始計時（往上數秒）
   - 你按「**結束本題，公布答案**」→ 顯示正解、各選項幾人選、最快答對是誰
   - **每題最快答對的人 +0.5 分**（課堂加分，和遊戲分數分開記）
5. **結束**：最後一題後按「放榜」
   - 按「**匯出本場成績 CSV**」下載這堂課的成績（名次、學號、姓名、分數、答對題數、課堂加分）
   - 按「**存入班級積分**」把成績累加到班級，之後在 `/class` 用班級代碼＋管理碼查看與匯出累積成績

### 計分方式

| 項目 | 說明 |
|---|---|
| 遊戲分數 | 答對 500 分 + 速度分（最多 500，手動模式以 30 秒為基準）+ 連中加分，最後一題 ×2 |
| **課堂加分** | 每題**最快答對**的人 +0.5，累計後可直接當期末加分 |

分數由伺服器計算，公布答案之前手機拿不到答案。

### 課堂分組競賽

適合上課用：學生分組搶答，成績累積起來當期末加分依據。

1. **開考場時填「班級代碼」**（例如 `程式設計-115-1`）。第一次使用會產生一組**六碼管理碼**，請記下來——之後開考場存分、查看積分都要用。
2. **上傳分組名單**（選填）：CSV 三欄「學號,姓名,組別」，UTF-8 或 Big5 都可以（Excel 存出來的檔直接上傳即可）。
   - 上傳後學生只要輸入**學號**，姓名與組別自動帶出，不能冒名。
   - 主持台會顯示各組報到人數，以及還沒到的人。
   - 名單存在班級裡，下次開同一個班級會自動帶出。
3. **沒有名單也能玩**：選「分組賽」後設定隊伍數，學生加入時自己選隊。
4. **隊伍分數 = 隊員平均分**，各組人數不同也公平；每題公布時顯示隊伍排名與升降。
5. **放榜**先頒隊伍冠亞季軍，再看個人成績。按「**存入班級積分**」就把這場成績累加到班級。
6. **查看與匯出**：打開 `/class`，輸入班級代碼與管理碼，可以看到每位學生的累積積分、場次、答對率與隊伍累積，並**匯出 CSV**（含 BOM，Excel 直接開）當期末加分依據。沒有管理碼的人看不到名單。

### 多人對戰（同場即時搶答）

1. 主持人在電腦開 `http://127.0.0.1:5000/host`，選分類、題數（5／10／15／20）、每題秒數（10／15／20／30），按「開考場」
2. 畫面會顯示四位數房號和 QR code（程式會自動換成區網 IP，手機掃了就能連）；建議投影到大螢幕
3. 玩家用手機掃 QR code，或打開首頁 →「多人對戰」→ 輸入房號、暱稱加入
4. 主持人按「開始考試」，所有人同時作答；全員作答完或時間到就公布答案
5. 公布時顯示正解、每個選項幾人選、最快答對的人、目前前五名與名次升降
6. **最後一題分數加倍**，最後放榜：狀元、榜眼、探花；主持人可「再來一局」

計分：答對 500 分 + 速度分（最多 500）+ 連中加分（每連中一題 +100，最多 +500），最後一題 ×2。答案只存在伺服器，公布前手機拿不到。

技術：即時推播用 **Server-Sent Events（SSE）**，純 Flask 就能做，不必另外安裝 WebSocket 套件；玩家重新整理頁面會自動回到原本的位置。一間房最多 100 人。

## 單人玩法

- 每局 10 題，3 條命，答錯或超時扣一條
- 答得越快分數越高；連中 3 題 ×1.5、連中 5 題 ×2
- 道具（每局各一次）:刪去兩個選項、跳過此題、加時 10 秒
- 題型：選擇題、是非題、排序題（時間軸）
- 依正確率放榜：狀元、榜眼、探花、進士、秀才

## 排行榜

- 結算時輸入暱稱即可「題名上榜」，可切換**本週榜 / 總榜**與各分類
- 前三名顯示為狀元、榜眼、探花；本週榜每週一 00:00（台灣時間）重新開始
- 成績存在 `leaderboard.db`(SQLite，第一次執行自動建立，不用另外架資料庫）
- **防作弊**:分數完全由伺服器計算——伺服器記錄每題顯示與作答的時間、檢查題號順序、道具每局限用一次、一局只能上榜一次，前端送不了假分數
- 暱稱會過濾 HTML 字元與不雅字詞(`leaderboard.py` 的 `BLOCKED` 可自行擴充）
- 清空排行榜：刪除 `leaderboard.db` 後重新啟動

## 備援：部署到 Render（雲端）

學生用自己的行動網路就能玩，不必和老師同一個 Wi-Fi，也不受校園網路的裝置隔離影響。
步驟見 `DEPLOY-Render.md`，部署設定已寫在 `render.yaml`（免費方案、單一 worker、多執行緒、健康檢查 `/api/health`）。
小抄：`docs/Render備援小抄.html`。

免費方案的三個限制：閒置 15 分鐘休眠、資料不保證保存（每堂課請立刻匯出 CSV）、資源有限（約 40～50 人）。

## 學校網路可能遇到的狀況

多人模式是**學生手機直接連到老師電腦**，所以卡關幾乎都在網路，不在程式。上課前務必在同一間教室先測一次。

| 狀況 | 現象 | 解法 |
|---|---|---|
| **Wi-Fi 裝置隔離**（AP isolation） | 手機連得上網，但打不開老師電腦的網址 | 最常見。請網管針對該 SSID 關閉隔離，或改用下面的備案 |
| **電腦與手機不同網段** | 電腦插網路線、手機連 Wi-Fi | 讓電腦也連學生用的同一個 Wi-Fi |
| **防火牆擋 5000 埠** | 電腦自己開 127.0.0.1 正常，手機連不到 | Windows 第一次執行時會跳出防火牆詢問，要按「允許存取」（專用網路）；已擋掉的話到「Windows Defender 防火牆 → 允許應用程式」把 Python 打勾 |
| **電腦有多張網卡** | QR code 的網址連不到 | 主持台的房號下方有「手機連不到？換一個網址」，可以逐一切換 |
| **校園網路要認證** | 手機沒登入校園網路 | 學生先連上並完成認證，再掃 QR code |

**先測通不通**：手機瀏覽器開 `http://<電腦IP>:5000/api/health`，看到 `ok: true` 就表示連得通。

**備案（建議先準備）**

1. **自備無線路由器或旅行路由器**：插電開機，電腦和學生都連這台（不必接網際網路，純區網就能玩）。最穩。
2. **手機熱點**：老師開熱點，電腦連上去；缺點是多數手機只能接 5～10 台，適合小班或臨時救急。
3. **部署到雲端**（Render、Railway 等免費方案）：學生用自己的行動網路就能玩，完全避開校園網路。缺點是免費方案會休眠，且重新部署時 `leaderboard.db` 可能被清空——每堂課結束後記得先按「匯出本場成績 CSV」。

**關於「加到主畫面」**：用 `http://192.168.x.x` 這種網址時，Android Chrome 通常不會提供「安裝應用程式」（瀏覽器規定要 HTTPS）。iPhone Safari 的「加入主畫面」則不受限制。要讓 Android 也能安裝，需要把服務部署到有 HTTPS 的網址。

## 新增題目

在 `questions/*.json` 加一筆即可，重新啟動 `app.py` 生效：

```json
{
  "id": "tw-017",
  "category": "文化",
  "difficulty": 2,
  "topic": "geo",
  "type": "choice",
  "question": "題目文字",
  "options": ["選項A", "選項B", "選項C", "選項D"],
  "answer": 1,
  "explanation": "答案說明",
  "fun_fact": "冷知識(可留空)"
}
```

- `type: "choice"`:`answer` 是正確選項的索引（從 0 開始）
- 是非題：`options` 設為 `["對", "錯"]`,`answer` 為 0（對）或 1（錯）
- `type: "order"`:`answer` 是依正確順序排列的選項索引，例如 `[2, 0, 3, 1]`
- `difficulty`:1~3，影響得分，每局會由易到難排序

要新增分類，在 `app.py` 的 `CATEGORIES` 加一行，並在 `static/index.html` 的 `SEAL` 設定印章字。

- **未設定 API key**:抓今日新聞標題，玩「猜版面」（這則新聞在國際、財經、體育……哪一版？）

```bash
export ANTHROPIC_API_KEY=sk-ant-...

```

## 上線給一般大眾

- 進行中的遊戲和多人房間都存在記憶體，重啟就清空
- 請用**單一 worker、多執行緒**啟動：`gunicorn -w 1 --threads 100 app:app`（多人模式每位玩家占用一條連線，執行緒數要大於同時上線人數）
- 前面若有 Nginx，SSE 路徑 `/api/mp/stream` 要關閉緩衝（程式已送出 `X-Accel-Buffering: no`）
- 部署可用 Render、Railway、Fly.io，或學校主機
- 只想放靜態網頁：執行 `python build_standalone.py`，上傳 `standalone.html` 即可（只有單人模式，沒有新聞分類，答案在網頁原始碼裡）
