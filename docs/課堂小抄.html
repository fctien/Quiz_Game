管理碼開班時只顯示一次，請立刻抄在這裡。

一、上課前 15 分鐘

  1. 電腦連上學生會用的那個 Wi-Fi（不要只插網路線）。
  2. 連點兩下 啟動-Windows.bat（Mac 是 啟動-Mac.command），瀏覽器會自動打開主持台。
  3. Windows 跳出防火牆詢問 → 按「允許存取」，並勾選專用網路。
  4. 拿一支手機開 http://電腦IP:5000/api/health，看到 ok: true 才算連得通。
連不通就先換網址：主持台房號下方的手機連不到？換一個網址可逐一切換（筆電常有多張網卡）。

二、開考坊設定

項目選什麼
主題Python（500 題）或 Deep Learning（708 題）
題數5 或 10（10 題約 15 分鐘）
每題秒數手動　← 由你控制開始與結束
賽制個人賽
班級代碼例如 Python-115-1（要累積成績才填）
管理碼第一次開班留空，之後填抄下來的六碼
分組名單選填。CSV 三欄：學號,姓名,組別

按 開考坊 → 畫面出現四位數房號與 QR code，投影給全班看。

三、學生加入

  • 手機掃 QR code，或開 http://電腦IP:5000 → 多人對戰 → 輸入房號。
  • 填學號與姓名（有上傳名單時只要學號，姓名自動帶出）。
  • 主持台右側即時顯示報到名單；有名單時還會列出未到的人。

四、每一題的流程

  1. 按 開始考試（之後是 下一題）→ 題目同時出現在大螢幕與所有手機上，秒數往上數。
  2. 等大家作答，畫面顯示「已作答 ○ / ○ 人」。全部答完也不會自動公布，一定等你按。
  3. 按 結束本題，公布答案 → 顯示正解、各選項人數、最快答對是誰。
  4. 講解完按 下一題；最後一題按鈕會變成 放榜。

五、計分 分數由伺服器計算，公布前手機拿不到答案

+0.5 分每題最快答對的人，課堂加分（期末加分用）
遊戲分數答對 500 ＋ 速度分 ＋ 連中加分；最後一題 ×2

六、下課前一定要做

  1. 放榜畫面按 匯出本場成績 CSV → 下載這堂課的成績（名次、學號、姓名、分數、答對題數、加分）。
  2. 按 存入班級積分 → 成績累加到班級。
  3. 之後開 http://電腦IP:5000/class，輸入班級代碼＋管理碼，可看累積成績並匯出 CSV。
先匯出，再存入。關掉考坊後這場的 CSV 就下載不到了。

七、當場排錯

狀況怎麼辦
學生打不開網址手機先連上校園 Wi-Fi 並完成認證；再按「換一個網址」試其他 IP
全班都連不到多半是 Wi-Fi 裝置隔離或防火牆。改用自備路由器／手機熱點，電腦與學生都連它
某位學生斷線請他重新整理頁面，會自動回到原位，分數不會不見
有人手機沒電／沒帶可以兩人共用一支，或用電腦瀏覽器加入
題目太難下課後編輯 questions/python.json 刪改；或改選題數少一點
主持台不小心關掉重開 /host 會自動回到原本的房間（同一個瀏覽器）
要重玩一輪放榜後按「再來一局」，題目重新抽、分數歸零

八、給學生的一句話

「連上 Wi-Fi，掃 QR code，輸入學號和姓名。每題我喊開始你們就搶答，最快答對的人加 0.5 分，算進期末成績。」
