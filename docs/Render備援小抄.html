一、把程式推上 GitHub 只做一次

  1. 電腦先裝 Git for Windows（git-scm.com/download/win，全部按預設）。
  2. 在 quiz_game 資料夾雙擊 推上GitHub.bat。
  3. 跳出 GitHub 登入視窗 → 用瀏覽器授權一次。
  4. 看到「推送完成」，到 github.com/fctien/Quiz_Game 確認檔案上去了。

儲存庫設 Private 也沒關係，Render 連得到。

二、在 Render 建服務 只做一次，約 5 分鐘

  1. 開 render.com → Get Started → 用 GitHub 帳號登入。
  2. 授權畫面選 Only select repositories → 勾 Quiz_Game → Install。
  3. 主控台按 New ＋ → Blueprint。
  4. 選 Quiz_Game → Connect。
  5. Render 自動讀到 render.yaml，列出服務 pulse-quiz（Free、Singapore）。Branch 選 main。
  6. 按 Deploy Blueprint，等 2～5 分鐘。
  7. 狀態變成綠色 Live，把上面的網址抄到左上角那一格。

三、測試 一定要用手機行動網路測

  1. 手機關掉 Wi-Fi，只用 4G/5G。
  2. 開 你的網址/api/health。
  3. 看到 {"ok": true, ...} 就成功。
  4. 再開首頁，版本要看到 v5.8。
測過一次以後，上課當天只要開主持台就好。

四、上課當天

  1. 提前 5 分鐘先開一次網址把它叫醒（免費方案會休眠，第一次要等約 1 分鐘）。
  2. 電腦開 你的網址/host，投影到大螢幕。
  3. 選主題 → 選單元 → 題數 → 秒數（自己控題選手動）→ 賽制 → 填班級代碼。
  4. 按 開考坊，螢幕出現四位數房號與 QR code。
  5. 學生掃 QR 或輸入房號加入；QR 會自動是雲端網址。
  6. 每題按 結束本題，公布答案 → 下一題。
  7. 放榜後先按 匯出本場成績 CSV，再存入班級積分，最後關閉考坊。
先匯出，再關閉。雲端版的資料庫會被清掉，關了就下載不到。

四之一、印一張 QR 用整學期

  1. 開考坊時，在「固定入口代碼」填一組英數字，例如 PY115（每門課一組）。
  2. 開 你的網址/qrcard，輸入同一組代碼與課程名稱 → 列印。
  3. 把這張 A4 貼在講義封面或教室公布欄。
  4. 之後每週學生掃同一張 QR，就會自動進入你當下開著的考坊。
還沒開考坊時，學生手機會停在「老師還沒開始」的等待畫面，你一按開考坊他就自動進場。 代碼要和開考坊時填的完全一樣，而且這張卡指向雲端網址，那天要用雲端版。

四之二、只有手機也能主持

  1. 手機瀏覽器開 你的網址/host，介面跟電腦一樣，不用另外裝東西。
  2. 設定好按 開考坊。
  3. 學生看不到你的螢幕，所以按 複製邀請連結，貼到班級 LINE 群組 （或直接念房號）。
  4. 考坊開著的時候螢幕不會自己鎖掉，你不用一直解鎖才能按「下一題」。
  5. 放榜後按 分享成績，直接把 CSV 傳到 LINE 或雲端硬碟，不用先下載再找檔案。

沒有投影機時就用這個方式。記得上課前 5 分鐘先開一次網址叫醒服務。

五、免費方案的三個限制

事項對策
閒置 15 分鐘會休眠
下次開要等約 1 分鐘		上課前 5 分鐘先開一次網頁
不能掛硬碟
重啟後排行榜與班級積分會清空		每堂課結束立刻匯出 CSV，成績以 CSV 為準
每月 750 小時
整個工作區共用		只留這一個免費服務就不會超過

0.1 CPU／512 MB。55 人可行，但每題會比區網多等 1～2 秒。人多的時候優先用區網，雲端當備援。

六、要更新程式的時候

在 quiz_game 資料夾雙擊 推上GitHub.bat， Render 會自動重新部署，約 2～3 分鐘生效。不用回 Render 按任何東西。

七、卡住的時候

症狀處理
Render 找不到我的 repoGitHub → Settings → Applications → Render → 加選 Quiz_Game
Build 失敗 ModuleNotFoundError確認 GitHub 上有 requirements.txt，再推一次
網頁打不開／一直轉圈冷啟動中，等 1 分鐘；仍不行就看 Render 的 Logs 最後一行
學生加不進來網址有沒有打錯、房號是四位數字、是不是剛好在冷啟動
說「這個學號正在線上」同一個學號在別台裝置上。用同一個學號重新加入就會接手原本的位子
學生畫面停在上一題解鎖手機、切回那個分頁,十幾秒內會自己接回來
畫面還是舊版版本不是 v5.8 就是快取，按 Ctrl+Shift+R
房號突然失效服務重啟會清掉進行中的考坊，重開一間即可

八、區網 vs 雲端

區網Render
學生網路同一個 Wi-Fi4G 都行
會被校網擋有可能不會
成績保存存在電腦，穩當場匯出
裝成手機 AppAndroid 不行可以

建議主要用區網，雲端當備援，當天哪個通就用哪個。
