一、一次性設定 上課前幾天做，約 20 分鐘

  1. 程式推上 GitHub（Render 從 repo 部署）。在 quiz_game 資料夾開 PowerShell：
    git init
    git add -A
    git commit -m "金榜問答"
    git branch -M main
    git remote add origin https://github.com/你的帳號/jinbang-quiz.git
    git push -u origin main
    解壓縮「含git紀錄」那份的話，前三行可以省略。儲存庫設 Private 也可以。
  2. 建立服務：到 render.com 用 GitHub 登入 → New → Blueprint → 選這個 repo → Apply。專案裡的 render.yaml 已經寫好設定，不用自己填。
  3. 等 2～5 分鐘，狀態變成 Live，複製網址填到左上角。
  4. 測試：手機關 Wi-Fi、只用行動網路，開 你的網址/api/health，看到 ok: true 就成功。
免費方案不需要信用卡。第一次部署較久，之後每次 push 會自動重新部署。

二、上課當天

  1. 上課前 5 分鐘先開一次網頁把服務叫醒（休眠中第一次開要等 30～60 秒）。
  2. 開 你的網址/host，照平常方式開房（主題 Python、秒數手動、個人賽、班級代碼）。
  3. QR code 會自動變成雲端網址，學生用 4G 或任何 Wi-Fi 都能加入。
  4. 每題流程、加 0.5 分的規則，都和區網版一模一樣。
  5. 下課前一定要按「匯出本場成績 CSV」，再按「存入班級積分」。
雲端版的班級積分可能會被清空（見右欄），成績以你匯出的 CSV 為準。

三、免費方案的三個限制

限制對策
閒置 15 分鐘會休眠

資料不保證保存

四、兩種方案比較

區網（你的電腦）Render（雲端）
學生上網方式必須同一個 Wi-Fi4G／任何網路
會被校園網路擋有可能不會
速度最快慢 0.1～0.3 秒
成績保存穩，存在你電腦要當場匯出
Android 裝成 App不行（非 HTTPS）可以
要不要開電腦要，且要一直開著不用

建議：主要用區網，Render 當備援。兩邊都先設好，當天哪個通就用哪個。

五、排錯

狀況怎麼辦
開網頁一直轉圈服務在休眠喚醒，等 30～60 秒；再不行看 Render 的 Logs 分頁
部署失敗（Failed）看 Logs 最後幾行，把訊息貼給 Claude
學生說連不上確認網址開頭是 https；請他關掉 VPN
房號不見了服務重啟會清掉進行中的房間，重開一間即可
成績不見了只能靠當場匯出的 CSV，沒有其他備份
改了題目要更新git add -A → git commit -m "更新題庫" → git push，Render 會自動重新部署
